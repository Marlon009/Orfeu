# Orfeu
 Lira, agente de atendimento para uma loja de instrumentos musicais. Roda com LLM local (Ollama) ou por API (OpenAI, Gemini, Claude). Regras de negócio em Python, validador contra valores inventados, bateria de avaliação e interfaces de terminal, web e WhatsApp. Desafio técnico AI Engineer, Artefact.
